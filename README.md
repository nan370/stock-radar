# 股票看盘

A股行情、板块信号、个股技术分析与量化选股 —— 纯静态站点，可直接托管在 GitHub Pages。

## 页面

| 页面 | 说明 |
|---|---|
| `index.html` | 行情首页：8 大指数、市场温度条、板块涨跌排行、异动信号、资讯流、自选股 |
| `analyze.html` | 个股分析：K线三联图（量能/MACD）、缠论结构、威科夫 Phase A~E、交易计划、多因子评分 |
| `screen.html` | 量化选股：多因子筛选、交易计划、回测与分数分层校验 |

## 分析口径（选股页与分析页同源）

评分与交易计划全部来自 `model.js`，两个页面只是薄封装，**同一只票不会出现两套结论**。

- **五维打分**：结构 35 / 量价 22 / 动量 17 / 资金 13 / 风险 13，原始分按权重归一化到 100 分制。
  分析页拿不到主力净流入时，按其余四项权重折算到 100 分并标注「资金项缺数据」。
- **动量项用趋势效率**：`涨幅 / (ATR% × √N)`，而不是裸涨幅，避免与结构分共线。
- **交易计划**：买区宽度 ≤3%、止损夹在「1.1×ATR ~ 12%」、目标取最近压力 / 6×ATR / +15% 三者最小值，
  附带盈亏比闸门（≥1.5 可执行 / 1.2~1.5 减半 / <1.2 放弃）与按 1% 风险预算反推的仓位。
- **威科夫**：交易区间生命周期判定 A~E 段；区间宽度 >25% 时不硬套，直接判单边趋势。
- **无基本面字段**：本工具只用价量与资金流，70 分不代表可以买。

## 技术说明

- **零构建**：原生 HTML/CSS/JS，不需要 npm、不需要编译，克隆即可用。
- **行情数据**：浏览器直连腾讯行情接口（`qt.gtimg.cn`），指数 / 个股 / 板块实时报价。
- **板块清单**：`boards_tx.json` 内置 836 个行业与概念板块代码。
- **股票名称库**：`a_share_all.json` 全 A 股代码名称对照，用于名称搜索与自选添加。
- **账号与自选股**：基于云端数据库（`watchlist` 表），同时保留本地镜像，断网也能看已加的自选。

## 本地预览

```bash
# 任选其一
python -m http.server 8000
npx serve .
```

然后打开 <http://localhost:8000>。

> 直接双击 `index.html` 用 `file://` 打开，部分浏览器会因跨域策略拒绝加载 JSON，建议用上面的本地服务。

## 部署

仓库设置 → Pages → Source 选 `Deploy from a branch` → Branch 选 `main` / 目录选 `/ (root)` → Save。
约 1 分钟后可通过 `https://<用户名>.github.io/<仓库名>/` 访问。
