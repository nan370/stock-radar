# 股票看盘

A股行情、板块信号、个股技术分析与量化选股 —— 纯静态站点，可直接托管在 GitHub Pages。

## 页面

| 页面 | 说明 |
|---|---|
| `index.html` | 行情首页：8 大指数、板块涨跌排行、异动信号、资讯流、自选股 |
| `analyze.html` | 个股分析：K线、缠论、技术指标、操作建议，右侧自选栏可直接切换 |
| `screen.html` | 量化选股：多因子筛选、回测 |

## 技术说明

- **零构建**：原生 HTML/CSS/JS，不需要 npm、不需要编译，克隆即可用。
- **行情数据**：浏览器直连腾讯行情接口（`qt.gtimg.cn`），指数 / 个股 / 板块实时报价。
- **板块清单**：`boards_tx.json` 内置 836 个行业与概念板块代码。
- **股票名称库**：`a_share_all.json` 全 A 股代码名称对照，用于名称搜索与自选添加。
- **账号与自选股**：基于云端数据库（`watchlist` 表），同时保留本地镜像，断网也能看已加的自选。

## 本地预览

```bash
# 任选其一
python -m http.server 8000
npx serve .
```

然后打开 <http://localhost:8000>。

> 直接双击 `index.html` 用 `file://` 打开，部分浏览器会因跨域策略拒绝加载 JSON，建议用上面的本地服务。

## 部署

仓库设置 → Pages → Source 选 `Deploy from a branch` → Branch 选 `main` / 目录选 `/ (root)` → Save。
约 1 分钟后可通过 `https://<用户名>.github.io/<仓库名>/` 访问。
