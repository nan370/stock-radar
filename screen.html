模型回测

数据源与交叉校验：页面同时接入东方财富、新浪财经、腾讯行情、同花顺四家公开行情，互相比对后才会出榜。全市场列表以东财与新浪并行获取（两家都成功时逐只比价，一致率低于 85% 会在页面上标红）；候选池 60 只用腾讯与东财各自再取一次逐只比价；最终入榜标的再用同花顺复核一次——同花顺返回带精确时间戳，可以算出快照时差并按差值动态放宽容差。通达信走的是私有 TCP 协议，浏览器无法直连，因此只作为上线前的离线校验基准，不参与页面实时取数。

为什么不要求价格完全相同：不同源的快照时刻本就不同。实测同一分钟内茅台分别为 1301.98（腾讯/新浪）与 1300.13（同花顺），差 0.14%，这是行情推送延迟而非数据错误。所以判定标准是「偏离是否超出按时间差放大的容差」，超出才标红。任何一只票的成交价如果被两家以上源否定，就不该拿它做交易决策。

价格口径分三态：盘中用实时价，最后一根日K未完成，成交量按交易进度折算全天预估，依赖它的判定标记「未确认」；已收盘用今日收盘价，K线完整，这批结果可直接用于次日开盘的委托规划；盘前 / 休市用上一交易日收盘，快照用大市值标的的日线重建。三者不会混淆——页面顶部与榜单上方都会写明当前用的是哪一种。

复权口径：结构计算统一使用后复权K线。前复权在除权日会产生跳空，凭空造出假笔与假中枢（同花顺那条线就是前复权，早期数据甚至出现负价，所以只用来核对最近价格、绝不参与结构计算）；页面上展示的中枢、支撑压力、买卖价已按复权因子换算回今日真实价，可直接对照盘面。

结构层级：月线 → 周线 → 日线 → 30 分钟四级串联。月线笔方向决定能不能做，周线结构决定做多大，日线买点决定在哪买，30 分钟用于入场时机。本引擎做「笔 → 中枢」两级，不做线段与走势类型递归——那部分参数敏感且对选股无增量贡献。

送样口径：威科夫事件（Spring / Upthrust / No Demand / No Supply / Climax / 放量滞涨 / 量价背离）全部为阈值判定，在最近 5 根K线窗口内检测并按距今天数衰减。

筛选口径：全市场约 5900 只不可能逐只拉多周期K线（约 2.4 万次请求），因此先用量价快照粗筛到 60 只候选（强势组 45 + 缩量回踩组 15），再逐只精算。候选池不覆盖全市场，会漏掉部分冷门标的。

入榜条件：综合分 ≥ 45、盈亏比 ≥ 1.2、日线结构未破坏、四级结构至少满足两级。四个条件任一不满足只进观察名单。高分不等于可买：观察名单里常有 70~85 分的票卡在盈亏比上，那是上方压力太近、空间不够赔率，不是评分算错了。

买卖价口径：买入区间宽度上限 3%，上沿不追过现价 1.5%、也不超过最近压力；止损取「跌破买点结构」与「跌破日线中枢下沿」中更近的一个，且距离被限制在 1.1 倍 ATR 至 12% 之间；目标位为最近压力，上方无压力时按中枢高度投影，上限取 min(最近压力, 6×ATR, +15%)。盈亏比 = (目标 − 区间中值) / (区间中值 − 止损)。

回测口径：信号确认后次日开盘成交（绝不用信号日收盘价，那是未来函数），且入场价距买点超过 4% 视为追高、直接放弃。费用按往返 0.2% 计（佣金 + 印花 + 滑点），止损为信号笔低点下方 1.5%，止盈 2R，最长持有 20 个交易日。一字板按买不进跳过。

样本局限：回测标的仅限本次入榜个股，不是全市场样本；区间约 3 年，含一轮下跌与一轮反弹。参数未做样本外调优，所有统计均为样本内结果，不代表未来收益。单只标的信号数常在 5–10 笔，统计不具显著性，请以汇总结果为准。

行情与K线来源：东方财富、新浪财经、腾讯行情、同花顺，四源交叉校验后出榜（通达信为离线校验基准）。结构计算与回测全部在本地浏览器完成，数据不上传。
